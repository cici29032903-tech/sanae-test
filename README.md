# sanae-test

ストーン&ユー向けのシンプルなLPサンプルです。

## 公開前に差し替える場所

`index.html` 内の以下のURLを、ご自身のURLに差し替えてください。

- `https://lin.ee/your-line-url`: LINE公式アカウントの友だち追加URL
- `https://jp.mercari.com/user/profile/your-mercari-id`: メルカリのプロフィールまたは商品ページURL

## Instagramでの使い方

Instagramのプロフィールリンクには、次の2通りの導線を用意できます。

1. すぐ相談したい方向け: LINEへ直接案内
2. 不安な方向け: このLPで内容を読んでからLINEへ案内

LP内にも「LINEで無料ミニ診断」と「まず詳しく見る」の2つの導線を置いています。
